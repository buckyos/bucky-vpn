# vpn-frame

## VPN 通道空闲生命周期
- 客户端运行时统一管理发送通道及其关联接收任务，以双向业务数据活动刷新空闲时间。
- 默认双向空闲 10 分钟后回收，后台每 30 秒检查一次；回收覆盖分发器持有、池内缓存和待复用通道。
- 活跃接收和正在执行的发送不因空闲清理而中断；后续发包通过既有工厂重新获得通道。公开隧道接口及协议格式保持不变。
- 通道关闭会唤醒正在等待写入、刷新或关闭的发送任务，使其返回错误并让后续发包恢复连接。

## 角色
客户端和服务端共用的 Rust 共享库，承载 VPN 协议类型和运行时内部逻辑。

## 输入
- 协议与网络需求
- 客户端与服务端的集成需求

## 输出
- 共享领域类型
- 客户端运行时子模块
- 服务端运行时子模块

## 依赖
- Tokio 异步运行时
- `vpn-frame/Cargo.toml` 中声明的协议和工具依赖

## 边界
- 负责复用型共享逻辑和领域抽象
- 不应吸收应用级打包和 UI 职责
