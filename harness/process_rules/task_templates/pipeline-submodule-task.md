# Retired Pipeline Submodule Task

Use the approved high-risk design's file/module dependencies and `harness/process_rules/task-template.md` for dependency-linked submodule handoffs. Each handoff names the canonical task manifest, stage, target module, change IDs, governing sources and done criteria.

Every subagent starts with `fork_turns: "none"`; the parent owns shared registration and lifecycle transitions. Scope Paths and stage manifests provide completion evidence and do not restrict file access. Execution modes, pipeline plans and admission stamps are retired; preserve their existing artifacts only as historical evidence.
